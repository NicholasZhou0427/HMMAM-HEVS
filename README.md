# HMMAM-HEVS

This repository is intended for the source-code release of the paper:

**Deep Reinforcement Learning With Hierarchical Multi-Module Attentions for Heterogeneous Electric Vehicle Routing Problem With Soft Time Windows**

The paper introduces the Hierarchical Multi-Module Attentions Model (HMMAM) for the Heterogeneous Electric Vehicle Routing Problem with Soft Time Windows (HEVS). HMMAM uses a hierarchical encoder-decoder architecture to construct routes through vehicle and node selection, accounting for both travel distance costs and soft time-window violation costs.
